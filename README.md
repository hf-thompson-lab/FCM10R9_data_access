# Forest Community Maps at 10 m resolution for Region 9 (FCM10R9)

This repo is for maintaining public access to the FCM10R9 dataset, which is a series of 10-m maps describing forest communities and attributes in 2021 over the Northeastern and Midwestern U.S., or Region 9 defined by the U.S. Forest Service.

## Data access

>[!NOTE]
> The release of the dataset is currently under some administrative process by U.S. Forest Service, so we've temporarily pulled down the links. We will make them available very soon!

The dataset can be accessed via
- Harvard Dataverse: https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DTFKCM
- Google Earth Engine (GEE) community data catalog: https://gee-community-catalog.org/projects/fcm10r9/.

Additionally, the AlphaEarth Foundation Satellite Embedding dataset can be found on the GEE data catalog: https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL
